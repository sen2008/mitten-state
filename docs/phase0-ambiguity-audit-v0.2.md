## 2. Ambiguity list

- **B2 — Tax-base definition + base/migration-lag form (narrowed).** Appendix §1. The base (dollar quantity the rate multiplies) is never defined or initialized, and the 4–8q base/migration lag has no functional form. Narrowing verified: the RATE-change lag HAS explicit form (50% Q+1, 100% Q+2 quarterly step, appendix line 59). Blocks item 2.

Bands are written proposals; the function they trigger on exists nowhere, and the coupling spec declares the gap itself. Note: the LANG spike contains an in-tree candidate formula (margin = 0.12 − 0.5×(logistics−1) − 0.3×(wageRatio−1) − 2.0×(corpRate−0.06) + noise + 0.02), but it is benchmark scaffolding, not adopted spec. Blocks item 3; item 4's event stream has no producer.
- **B4 — Household formation + spawn initial conditions.** Appendix §3 + coupling §4.4. Only "1–4, mean ~2.4" is written. Missing: earner definition, starting savings, payday weekday, and spawn employment assignment (who starts with a job, at which firm, at what wage — the placement pass handles transitions, not t0).
